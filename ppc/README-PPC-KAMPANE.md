# PPC kampaně – Aikido Mariánské Lázně

## Struktura kampaní

### 1. Aikido ML - Brand (Google + Sklik)
- **Cíl:** Zachytit lidi, kteří přímo hledají váš klub
- **Klíčová slova:** aikido mariánské lázně, budo club, aikido ml
- **Typ shody:** Phrase / Exact
- **Doporučený rozpočet:** 30–50 Kč/den
- **Max CPC:** 5–8 Kč (nízká konkurence)

### 2. Aikido ML - Bojové umění / Kurzy (Google + Sklik)
- **Cíl:** Oslovit lidi hledající bojová umění nebo sport v okolí
- **Klíčová slova:** bojové umění mariánské lázně, sebeobrana, aikido kurzy
- **Typ shody:** Phrase + Broad (sport ML)
- **Doporučený rozpočet:** 50–100 Kč/den
- **Max CPC:** 8–15 Kč

### 3. Aikido ML - Děti (Google + Sklik)
- **Cíl:** Rodiče hledající aktivity pro děti
- **Klíčová slova:** aikido pro děti, sport pro děti ML, kroužky ML
- **Doporučený rozpočet:** 50–80 Kč/den
- **Max CPC:** 10–15 Kč

### 4. Aikido ML - Seminář (Google + Sklik)
- **Cíl:** Propagace semináře v květnu 2026
- **Klíčová slova:** aikido seminář, aikido workshop, aikido stáž
- **Doporučený rozpočet:** 30–50 Kč/den (spustit ~3 týdny před akcí)
- **Max CPC:** 5–10 Kč

## Cílení

- **Lokace:** Mariánské Lázně + okolí 20 km (Cheb, Sokolov, Teplá)
- **Jazyk:** Čeština
- **Zařízení:** Všechna (mobily mají vyšší prioritu – lokální vyhledávání)
- **Denní doba:** Zvýšit nabídky 16:00–21:00 (lidé plánují večerní aktivity)

| Varianta | Denní rozpočet | Měsíční odhad |
|----------|---------------|---------------|

| Střední | 200 Kč/den | ~6 000 Kč/měsíc |
| Agresivní | 350 Kč/den | ~10 500 Kč/měsíc |

## Jak importovat

### Google Ads
1. Stáhnout Google Ads Editor
2. File → Import → Import from CSV
3. Nahrát `google-ads-kampane.csv`
4. Přidat negativní klíčová slova z `negativni-klicova-slova.csv`
5. Nastavit lokaci, rozpočet a CPC

### Sklik
1. Přihlásit se do Sklik.cz
2. Kampaně → Import → CSV
3. Nahrát `sklik-kampane.csv`
4. Přidat negativní klíčová slova
5. Nastavit lokaci na Karlovarský kraj / Mariánské Lázně + okolí

## Tipy pro optimalizaci

- **Konverze:** Nastavit sledování konverzí na klik na "Napište nám" a telefonní číslo
- **Rozšíření reklam:** Přidat sitelinky (Ceník, Pro děti, Rozvrh, Kontakt), rozšíření o volání (607 517 967), rozšíření o místo
- **Remarketingový seznam:** Návštěvníci webu za posledních 30 dní
- **Seminářovou kampaň** vypnout po 23. květnu 2026
